# 打包说明（PyInstaller 目录模式）

把本工具打包成**无需安装 Python 即可运行**的 Windows 程序。采用**目录模式**（onedir）：
启动快、杀软误报率低，发布时把 `dist\AstyleTool\` 整个文件夹压缩为 zip 即可。

---

## 1. 环境准备

- Windows 10 / 11，64 位
- Python 3.10.x（官方安装包自带 tkinter）
- 安装 PyInstaller（一次性）：

```powershell
pip install pyinstaller
```

## 2. 打包命令

在项目根目录（`main.py` 所在目录）执行：

```powershell
pyinstaller --noconfirm --windowed --name AstyleTool main.py
```

| 参数 | 作用 |
|---|---|
| `--windowed`（`-w`） | GUI 模式，**运行 exe 时不出现黑色控制台窗口** |
| `--noconfirm`（`-y`） | 覆盖旧的 build/dist 时不询问 |
| `--name AstyleTool` | 生成物名称 |
| 目录模式是 PyInstaller 默认行为 | 如需单文件模式另加 `--onefile`（启动较慢、更易被杀软误报，见第 5 节） |

可选：指定图标（需自备 `app.ico`）：

```powershell
pyinstaller --noconfirm --windowed --icon=app.ico --name AstyleTool main.py
```

打包完成后生成：

```
build\              # 中间产物，可删除
dist\AstyleTool\    # 发布目录
AstyleTool.spec     # 打包配置，可保留以便重复打包
```

### 2.1 使用 spec 文件打包（重复打包推荐）

首次打包会生成 `AstyleTool.spec`，它是 PyInstaller 的**构建配置脚本**，命令行的所有选项
都已固化在其中（如 `console=False` 对应 `--windowed`、`name='AstyleTool'` 对应 `--name`）。
之后重新打包只需：

```powershell
pyinstaller --noconfirm AstyleTool.spec
```

效果与第 2 节的完整命令完全等价。

spec 文件的价值在于**命令行表达不了的定制**，可直接编辑后用它打包：

| 需求 | 修改位置（示例） |
|---|---|
| 指定图标 | `EXE(..., icon='app.ico')` |
| 把 `.astylerc` 打进包里 | `Analysis(..., datas=[('.astylerc', '.')])` |
| 排除不用的标准库模块、减小体积 | `Analysis(..., excludes=['unittest', 'pydoc_data'])` |
| 关闭 UPX 压缩（部分杀软误报诱因） | 把 `EXE(...)` / `COLLECT(...)` 中的 `upx=True` 改为 `False` |

> 注意：`.gitignore` 的 PyInstaller 模板默认忽略 `*.spec`。如果决定以 spec 方式打包、
> 希望配置跟随仓库版本管理，执行 `git add -f AstyleTool.spec` 提交即可。

## 3. 部署资源（关键步骤）

程序运行时以 **exe 所在目录**为基准查找 astyle 与风格配置（`ui_main.py` 的 `APP_DIR`
在打包后取 `sys.executable` 所在目录）。需要把以下内容复制进 `dist\AstyleTool\`：

```powershell
Copy-Item .astylerc dist\AstyleTool\
Copy-Item astyle\astyle.exe dist\AstyleTool\astyle\
```

> 也可以直接运行仓库根目录的 `copy_deps.bat` 一步完成上述复制，脚本会先校验打包产物与依赖文件是否存在，复制后列出发布目录内容。

完成后发布目录结构：

```
dist\AstyleTool\
├── AstyleTool.exe       # 主程序（双击运行，无黑窗口）
├── .astylerc            # 默认风格配置
├── astyle\astyle.exe    # Artistic Style 3.6.20
├── python310.dll 等     # PyInstaller 生成的运行时文件，不可删
└── _internal\           # PyInstaller 6.x 的依赖目录，不可删
```

运行后自动生成（无需预置）：

- `settings.ini` —— 界面配置，关闭窗口时写入
- `logs\` —— 每次运行的日志

> `astyle\file\`（官方风格示例）与 `astyle\doc\`（文档）与运行无关，发布时可省略以减小体积。

## 4. 发布与验证

1. 把 `dist\AstyleTool\` 整个文件夹压缩为 zip（或直接拷贝到目标机器）。
2. 在**未安装 Python** 的环境（或本机临时改掉 PATH）双击 `AstyleTool.exe`：
   - 窗口正常打开，无黑色控制台窗口；
   - 三个路径框默认值已填好 `astyle\astyle.exe` 与 `.astylerc`；
   - 点"刷新"能看到 `Artistic Style Version 3.6.20`；
   - 勾选"预览模式"跑一次，确认扫描、日志、弹窗正常。

## 5. 单文件模式（可选，不推荐）

```powershell
pyinstaller --noconfirm --onefile --windowed --name AstyleTool main.py
```

- 优点：只有一个 exe，拷贝方便；
- 缺点：每次启动需解压到临时目录（首次慢 1–2 秒）；`.astylerc` 与 `astyle\` 仍需放在
  exe 旁边（程序按 exe 目录找资源）；被杀软误报的概率明显更高。

## 6. 常见问题

**Q：双击 exe 闪退？**
A：多为资源缺失或依赖不全。先用带控制台的方式复现错误：临时去掉 `--windowed` 重新打包，
在命令行里运行 `dist\AstyleTool\AstyleTool.exe` 查看报错输出。

**Q：提示找不到 astyle 或 .astylerc？**
A：确认二者已按第 3 节复制到 exe 同级目录；路径框里的值也可在界面中手动修改。

**Q：杀软报毒？**
A：PyInstaller 打包的程序存在误报可能，目录模式概率较低。可向杀软提交白名单，或改用
代码签名证书签名后发布。

**Q：如何重新打包？**
A：重复第 2 节命令，或直接用 `pyinstaller --noconfirm AstyleTool.spec`（见 2.1 节）；
`--noconfirm` 会覆盖旧产物。修改了依赖或资源时建议先删除 `build\` 与 `dist\`。
